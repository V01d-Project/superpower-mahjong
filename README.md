# 超能力三麻 · 单机实验版

React + TypeScript + Vite；你与两位 AI。纯静态前端，**没有联机房间或权威服务器，不是假联机**。规则核心自行实现，没有第三方麻将库。

## 本地运行


```sh
npm install
npm test
npm run build
npm run dev
```

Windows 终端如拦截 npm.ps1，请用 npm.cmd 或 cmd /c "npm test"。

点击手牌，再点「打出」。听牌时选择合法弃牌可立直。手机手牌可左右滑动，每张可点击的手牌至少 44px 宽。主动开局选择，每局一次；A03 护运为默认被动。所有规则计算在 Worker，不阻塞牌桌 UI。transport.ts 为未来服务端留出接口；当前只有 LocalTransport。

默认每人 35000 点、50 运。准备页「实验设置」可调整三家起始运气并输入固定种子。该设置是明确标注的单机测试选项，不是暗中扶弱。下一局保留点数与漂移后的运气，重新配牌。

## 已实现

- 108 张唯一物理 ID，去二至八万，赤五筒/索，禁吃；碰、明杠、暗杠、拔北及抢北响应。
- 王牌 14 张：10 个指示/里指示槽位，4 槽补牌队列，由活牌尾部补入；单测覆盖连续四次杠加四次拔北，八次补牌不重复实体，不移动指示牌。补牌不受运气加权。
- 普通/七对子/国士向听与待牌；舍牌、同巡、立直振听；荣和优先、双响、自摸损、立直棒、荒牌罚符与结算幂等。
- 立直、一发、门清自摸、断幺、平和、一杯口/二杯口、役牌、岭上、海底/河底、七对、对对、三暗刻、三杠、三色同刻、一通、混全/纯全、混老头、小三元、混/清一色。
- 国士、四暗刻、大三元、大小四喜、字一色、绿一色、清老头、九莲、四杠役满。单牌型不双倍，复合役满叠加；番符计分到满贯、跳满、倍满、三倍满、累计/普通役满。
- 宝牌、里宝牌、赤牌、拔北加番；必须先有起和役，不能靠宝牌和牌。牌桌公开宝牌指示、供托、三家运气数值与能力状态。
- A01 抢运、A02 观山、A03 护运、A06 封印、A07 改一张、A10 均衡。资源先付、护运自动反制、正收益每局最多 15；封印只禁主动，不禁麻将操作。
- A07 交换真实物理牌、不凭空复制，第三次弃牌后可用，不能立即自摸，也不能以拔北/杠补牌绕过强制弃牌；无目标花色退运但耗次数。
- AI 摸打、立直、和牌、拔北、碰杠与简单现物防守；桌面/手机布局、河、副露、运气条、能力面板、和牌/流局结算、公开事件。
- 固定种子 xoshiro128**，洗牌/换牌/正常摸牌/能力使用独立随机流，整数拒绝采样。不是线上 ChaCha/HKDF/承诺协议。

## 运气配牌：重要的未达验收项

按设计 3.2 实现 Q=(-向听,进张)、固定候选权重、逐轮打散的正向 38 次/反向 1 次预算；50 运完全不消费换牌抽样，保持原洗牌结果。正常摸牌只做一次权重 600–1400 的抽样，不重抽，不保证进张。

**100 运起手约 50% 在一向听内：目前没有达成，不能宣传达标。** 独立 1000 个高运样本中，99.6% 进入一向听内、平均向听 0.073，远偏强于目标。0 运 2000 局平均 3.851，也比目标 3.60 更差。中性 20000 局平均向听 3.39045，与设计随机基线相容。详细分布、均值标准误、比例 Wilson 95% 区间见 calibration.json / CALIBRATION.md。此报告不是百万局认证。

scripts/sweep.cjs / budget-sweep.json 是预算影响的离线探索：只在内存替换预算，不改变游戏源代码，也不使用好牌模板或按初手重开。设计允许的 32–44 次预算不应擅自改成更小预算来冒充原方案；目标与算法的冲突须交设计者决定。当前仍保持 38 次配置并明确标记未达标。

- node scripts/soak.cjs：100 个固定种子完整对局，8476 次状态推进，75 局和牌、25 局流局；每次检查物理牌/点数守恒与运气范围，通过，详见 soak-results.json。
