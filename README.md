# 超能力三麻 · 单机实验版

React + TypeScript + Vite；你与两位 AI。没有联网房间或权威服务器，不是假联机。核心自行实现，没有第三方麻将规则库。

## 使用

npm install / npm test / npm run build / npm run dev

点击手牌，再点打出。听牌时选择合法弃牌后可立直。主动开局选择，每局一次；护运为默认被动。下一局保留点数和漂移后的运气。全部规则计算在 Worker；transport.ts 留有未来服务器接口。

- 国士、四暗刻、大三元、大小四喜、字一色、绿一色、清老头、九莲、四杠役满。单形不双倍，复合叠加。番符、宝牌/里/赤/拔北，先有役才能加宝牌。

## 重要：尚未通过的验收

**100 运起手约 50% 进入一向听以内，未达成。** 使用设计 3.2 的 Q 字典序、38 次正向 / 1 次反向预算、固定候选权重与逐轮打散，但探索样本与目标明显不符。没有偷偷重开种子或模板配牌。

运行 node scripts/calibrate.cjs 重现 calibration.json：中性 200 局平均 3.325；100 运 50 局平均 0.12，一向听以内 98%；0 运 50 局平均 3.68。样本很小，非训练/百万局验收，**不能宣传概率达标**。应进一步校验算法口径并经设计者决定参数/容差，当前发布仅为可玩实验原型。

未实现：完整东风/半庄赛制与连庄延长（当前无限练习局，座位0固定庄）、加杠/抢杠、立直后杠、双立直、天和地和、中途流局、流局满贯、包牌；王牌补牌物理映射未做雀魂牌谱兼容认证。没有存档、回放验证、线上承诺/密钥协议、账号或多人网络。无 300 例边界/百万局统计/真人平衡认证。
