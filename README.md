# 超能力三麻 · 单机实验版

React + TypeScript + Vite；单机是「你与两位 AI」，联机是三人建房。默认 P2P：房主浏览器持有权威牌局，通过 PeerJS 公共 broker 交换信令，游戏消息通过 WebRTC DataChannel 传输。分享完整的 `sanma-…` 房间号即可加入，不需要账号或启动自己的服务。规则核心自行实现，没有第三方麻将库。

联机连接方式也保留「局域网/自建服务器」：`npm run server`，默认 8787 端口，填写 `ws://` 或 `wss://` 地址。两条路径共用 `src/rooms.ts` 的房间、合法操作、脱敏与断线托管逻辑，`server/rooms.ts` 仅重新导出。

P2P 房主必须保持页面打开，房主退出或刷新会结束房间，加入者会看到「房主已离开」；连接异常有提示和心跳检测。加入者刷新后不能恢复原 P2P 座位，需重新建房；原 ws 路径的断线重连和刷新恢复仍保留。P2P 仍依赖公共信令及可用的 ICE 网络，不能保证所有 NAT/防火墙环境直连，也没有房主迁移或持久化。房主可访问完整牌局，只适合互相信任的朋友局。

## 本地运行


```sh
npm install
npm test
npm run build
npm run dev
```

Windows 终端如拦截 npm.ps1，请用 npm.cmd 或 cmd /c "npm test"。

点击手牌，再点「打出」。听牌时选择合法弃牌可立直。手机手牌可左右滑动，每张可点击的手牌至少 44px 宽。主动开局选择，每局一次；A03 护运为默认被动。单机规则计算在 Worker；联机分别通过 OnlineTransport（ws）或 P2PTransport 连接权威房间。

P2P 浏览器验收：`npm.cmd run build` 后运行 `node scripts/p2p-browser-test.cjs`。脚本自动启动 Vite preview，使用 headless Chrome、两个浏览器上下文和三个玩家页面，检查公共牌面、同一弃牌、房主离开及单机完整一局；结果写入 `p2p-browser-results.json`。此验收实际访问公共 broker；单元测试使用假 transport，不访问公网。

默认每人 35000 点、50 运。准备页「实验设置」可调整三家起始运气并输入固定种子。该设置是明确标注的单机测试选项，不是暗中扶弱。下一局保留点数与漂移后的运气，重新配牌。

## 运气配牌：端点独立校准（非正式验收）

保留 Q=(-向听,进张)、固定候选权重及逐轮打散的正向 38 次/反向 1 次预算，不改洗牌、不重开种子。严格改善/恶化后再概率接受：正向按当前向听 ≥3 / 2 / ≤1 分别为 20% / 15.5% / 2%，反向 40%。这是本次接受策略扩展，用来避免连续爬山过强；不是削减尝试预算。50 运仍保持原随机发牌，正常摸牌的 600–1400 单次弱加权未变。

新独立种子 acceptance-holdout-v6- 的实测：L=0 共 5000 局，平均向听 **3.588**、一向听以内 **0.660%**；L=50 共 20000 局，平均 **3.39795**、一向听以内 **1.165%**；L=100 共 2000 局，平均 **1.579**、一向听以内 **51.100%**。

**本次三档点估计均进入设计目标窗口；不能当作百万局正式概率认证。** 完整直方图、均值标准误、均值及比例 95% 区间见 calibration.json / CALIBRATION.md。置信区间并非全部落在目标窗口内，尚未测齐多人高运竞争、座次公平性与每 5 点扫描。

训练参数网格每档 200–500 局。首轮独立验证比例 53.04% 仍偏强，失败记录保留于 acceptance-holdout-v5-failed.json；二次冻结后换全新 v6 种子验算，没有用旧验证集冒充独立样本。复现：node scripts/calibrate.cjs 2000（高运 2000、负运至少 5000、中性至少 20000）。历史预算探索文件仅供参考，不是当前生产参数。

## 本次补齐：固定东四局与加杠

本版本按任务指定采用东一至东四（区别于设计原稿默认东三），座位 0 起庄。庄家和牌或荒牌听牌连庄，否则按 0→1→2→0 轮庄；东四换庄时结束，任一家负点立即结束，恰好零点继续。无目标点提前止、无延长场。局间保留点数、供托、漂移后的运气和装配，重置局内状态。终局按点数降序、初始座次打破同点排序，剩余供托给第一名。

自己摸牌后可把已碰的刻子升级为加杠（杠按钮）；先给其他两家荣和窗口。抢杠计一番并由加杠者放铳；振听照常限制，跳过产生同巡或立直振听。无人抢杠才确认第四张、增加杠数、按原流程翻杠宝牌和补牌，既有指示牌槽不移动。仅加杠可抢，暗杠无抢杠窗口；立直后禁止加杠及暗杠。无活牌或已四杠禁止新杠。AI 会加杠及抢杠，单机、P2P、ws 均复用 engine/rooms。
